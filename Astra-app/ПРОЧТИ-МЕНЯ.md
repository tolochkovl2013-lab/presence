# Astra — приложение для Windows

Это не сайт: `Astra.exe` — настоящая программа с иконкой, окном и иконкой в трее.
Внутри неё VRM-аватар поверх всех окон, нейронный голос и доступ к компьютеру.

## Как запустить

1. Двойной клик по **`Astra.exe`**.
2. Если Windows спросит про SmartScreen — «Подробнее» → «Выполнить в любом случае»
   (файл собрана на вашем же компьютере, из исходников в папке `public`).

Приложение само поднимает локальный бэкенд `server.js` на `127.0.0.1:4780`.

## Что умеет

| Раздел | Что делает |
|---|---|
| **Главная (чат)** | открывает программы и сайты, погоду, список окон, скриншот, звук, буфер обмена |
| **Команды** | визуальные цепочки: триггер → действия, запускаются прямо на ПК |
| **Модель** | VRM-аватар, «Аватар на рабочий стол» — окно поверх всех, липнет к краю активного окна |
| **Голос** | нейронный голос Piper локально (без интернета), паузы, вдох, питч |
| **ИИ** | свой ключ OpenAI / OpenRouter / Grok / Ollama / LM Studio |
| **Плагины** | список установленных |
| **Настройки** | фон, пузыри, цвета, скорость анимации |

## Голос

Нейронные голоса лежат в `voices/`:
- `irina` — женский (аниме-девушка, с поднятым питчем)
- `dmitri` — мужской

Синтез идёт локально через `vendor/piper` — интернет не нужен, звук не уходит наружу.
В разделе «Голос»: скорость, высота, громкость, паузы между фразами, вдох.

## ИИ

Без ключа Astra отвечает заготовками и умеет управлять компьютером.
Чтобы она отвечала на что угодно — вставьте API-ключ в разделе «ИИ»
(OpenAI, OpenRouter, Grok, Ollama или LM Studio). Ключ хранится только локально
в `data/settings.json`.

## Замена модели

Положите свой файл `.vrm` в папку `models` с именем `astra.vrm` — он подхватится
сам. Или загрузите через кнопку «Загрузить VRM» в разделе «Модель».

## Файлы

```
Astra.exe          — приложение
public\            — интерфейс (index.html, app.js, style.css, pet.html, pet.js)
models\astra.vrm   — 3D-модель
voices\            — нейронные голоса
server.js          — локальный бэкенд (node)
Astra.bat          — запуск с проверкой node и зависимостей
```
