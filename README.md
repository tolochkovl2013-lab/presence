# Presence (Astra)

Локальный ИИ-ассистент для Windows: чат, голос (Piper, офлайн), аватар VRM поверх всех окон, реальное управление ПК.

## Запуск

```
npm install
node server.js        # http://127.0.0.1:4780
Astra.bat             # или Astra-app\Astra.exe — окно-приложение
```

## Что умеет

- ИИ через Gemini (бесплатный ключ Google AI Studio) или OpenAI / Claude / Grok / OpenRouter / Ollama / LM Studio.
- ИИ сам вызывает инструменты: открыть программу или сайт, печатать текст, горячие клавиши,
  звук, блокировка, список окон, скриншот, буфер обмена, погода, поиск файлов, запуск цепочек.
- Аватар VRM в отдельном окне: без рамки, поверх всех окон, липнет к краю активного окна.
- Голос: Piper (irina / dmitri), паузы между фразами, питч, скорость.
- Цепочки команд: визуальный редактор узлов, выполнение на бэкенде.

## Большие файлы в репозиторий не входят

Скачать отдельно и положить на место:

- `voices/irina.onnx`, `voices/irina.onnx.json` — русский голос Piper
- `models/astra.vrm` — модель аватара
- `vendor/piper/piper/piper.exe` — Piper

## Ключ

`data/settings.json`:

```json
{ "provider": "gemini", "apiKey": "...", "model": "gemini-4-hydrogen" }
```

Ключ хранится только локально и никуда не отправляется.
